## 真实两人试点门槛

需要公司自建应用、两员工 open_id、公司 tenant_key、应用权限审批、HTTPS 回调域名以及公司批准的模型端点。凭证应配置到本地/部署 Secret 文件，不发进聊天或提交仓库。
